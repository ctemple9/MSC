# Minecraft Server Controller (MSC) v0.1.50

- Fixed the macOS installer background leaving white margins at the right and
  bottom of its Finder window. The background now uses the correct resolution
  metadata to fill the configured window on Intel and Apple Silicon Macs.

Cameron verified the corrected layout in a local Intel DMG before this release.

The release workflow builds all nine desktop/headless packages, SHA-256 checksums
and signed update metadata. macOS desktop images are signed and notarized.
Windows packages remain unsigned and may display SmartScreen warnings. No test
suites were run for this release; physical acceptance of the published packages
remains pending. Local Bedrock on macOS continues to require an Intel Mac.
