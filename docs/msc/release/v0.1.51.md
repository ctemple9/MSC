# Minecraft Server Controller (MSC) v0.1.51

- Fixed first-time Bedrock setup on Intel Macs by starting the helper before
  the Background Service and recovering when helper readiness is delayed.
  Setup now offers an inline retry when local Bedrock remains unavailable.
- Fixed the macOS menu bar indicator appearing in the Dock. Reopening MSC
  restores the existing desktop window instead of opening another one.

The release workflow builds all nine desktop/headless packages, SHA-256 checksums
and signed update metadata. macOS desktop images are signed and notarized.
Windows packages remain unsigned and may display SmartScreen warnings. No test
suites were run for this release; owner verification of the fixes and published
packages remains pending. Local Bedrock on macOS continues to require an Intel Mac.
