# Minecraft Server Controller (MSC) v0.1.49

- Redesigned the Engine page around computer profiles, with clear install,
  repair, connection and service controls. Connected profiles show available
  RAM, selected server and a hidden-until-revealed computer address.
- Server cards show active-world thumbnails and let you set or change them
  without switching the selected server.
- Combined the first-launch welcome and How MSC works explanation, with a Next
  action and a button to reopen it. Added clearer server initiation progress,
  resume/discard actions and a guided walkthrough through setup and the app.
- Improved guided-tour placement and behavior around tabs, maps, dialogs and
  menus. Empty server lists now align their message and action to the left.
- Native Bedrock servers save console output to logs for troubleshooting.
- Remote sidebar Directory and Logs actions open folders inside MSC's Files
  tab instead of trying to open remote paths on the desktop computer.
- Source desktop builds can use the uninstall flow with its normal preview and
  confirmation; Linux development helpers refresh when the engine build changes.

Computer RAM and server-card thumbnail features require this engine version on
remote computers as well as the updated desktop app.

The release workflow builds all nine desktop/headless packages, SHA-256 checksums
and signed update metadata. macOS desktop images are signed and notarized.
Windows packages remain unsigned and may display SmartScreen warnings. No test
suites were run for this release; packaged-build physical acceptance remains
pending. Local Bedrock on macOS continues to require an Intel Mac.
