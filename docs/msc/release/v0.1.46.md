# Minecraft Server Controller (MSC) v0.1.46

- Server creation now includes RAM allocation and an inline Java executable
  field with Detect, Browse and Install Java. Java must be specified before
  continuing; the required version is shown for the selected Minecraft version.
- Import creation can open the existing Modrinth and CurseForge modpack browser.
- World creation sections use consistent spacing and collapsed Essentials,
  with simplified settings context and explanatory copy.
- Onboarding follows the updated creation flow, automatically reveals highlighted
  sections, and confirms before exiting the tour through the creator's Back button.
- Manage is now beside Start in the sidebar. Engine is the square E icon in the
  header, with a concise explanation of the background service and control panel.
- Connection combines sidebar addresses and enabled service controls. Disabled
  playit.gg and Xbox Broadcast services and their setup prompts are hidden.
- Detected Java runtimes in creation use the editor's compact list styling.
- Linux development startup can bootstrap its service helper without an RPM install.

Includes all nine desktop/headless packages, SHA-256 checksums and signed update
metadata. macOS desktop images are signed and notarized; other packages retain
their existing signing limits. No test suites were run for this release.
Windows and Mac physical verification of these changes remains pending.
Local Bedrock on macOS continues to require an Intel Mac.
