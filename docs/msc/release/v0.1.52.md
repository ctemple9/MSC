# Minecraft Server Controller (MSC) v0.1.52

- Corrected the Intel Mac Bedrock helper readiness check. The previous check
  incorrectly rejected a listening helper, causing first-time engine installation
  to time out and roll back.
- Administrator command failures no longer falsely claim authorization failed.
- Uninstall now recognizes the standard MSC data directory when no engine
  configuration exists, allowing cleanup after a failed or incomplete install.
- Uninstall lists items selected for removal by default. Uncheck paths to keep;
  uncertainty is shown as a warning rather than blocking the operation. Your
  confirmed choices reach the removal worker, and retained data no longer prevents
  removal of the app.

The focused Bedrock socket readiness regression passed locally (one test,
zero failures). It is not part of the release workflow. Published-package and
fresh-install physical verification remains pending.

The existing build-only workflow produces all nine desktop/headless packages,
SHA-256 checksums and signed update metadata. macOS desktop images are signed and
notarized; Windows packages remain unsigned. Local Bedrock on macOS requires an
Intel Mac.
