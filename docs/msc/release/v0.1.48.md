# Minecraft Server Controller (MSC) v0.1.48

- Windows now reads server process CPU and RAM usage for Overview and
  Performance. CPU becomes available after the initial sampling interval;
  its percentage represents the whole computer's processing capacity.
- Complete uninstall now recognizes Windows installers registered as
  Minecraft Server Controller, while retaining support for the older MSC name.
  An unrecognized package registration no longer claims the app must be a
  developer checkout.

Includes all nine desktop/headless packages, SHA-256 checksums and signed update
metadata. macOS desktop images are signed and notarized. Windows packages remain
unsigned and may display SmartScreen warnings. No test suites were run for this
release. Physical acceptance of the new packaged builds remains pending.
Local Bedrock on macOS continues to require an Intel Mac.
