# Minecraft Server Controller (MSC) v0.1.45

- The product is now Minecraft Server Controller (MSC). The always-on component
  is called Background Service in the interface, with engine used internally.
  Current repository links and updater defaults use `ctemple9/MSC`.
- Windows updates no longer reject a protected Program Files installation
  because an ancestor has an inheritance-only permission rule. Applicable
  write/delete permissions and trusted ownership remain checked.
- The background indicator correctly reports Windows lock contention as already
  running, preventing the misleading error 33 service-action message.
- Repair can replace an existing owned Windows service build while retaining
  its account, data directory and startup policy. Protected build verification
  is cached to reduce repeated status-refresh work.
- Provider catalog images are allowed through the desktop image policy, and
  CurseForge key entry is available where catalog searches need it.
- Server creation binds staged world inputs to the selected world context.

## Updating from an older Windows desktop

If 0.1.43/0.1.44 refuses an in-app update with the machine-protected-directory
message, download this release's `msc-0.1.45-windows-x86_64.msi` and install it
manually. The check lives in the older running desktop, so a corrected target
package alone cannot unblock that attempt. Installed-update, repair and rollback
acceptance remain pending; these notes do not claim those scenarios passed.

Existing service identities, data/credential locations and private update
protocols are retained for compatibility. Use the platform-specific package;
installer/archive filenames now start with `msc-`. The signed update manifest
and detached signature keep their established filenames for existing clients.

The release requires all nine desktop/headless packages, SHA-256 checksums and
signed update metadata. macOS desktop images are signed and notarized; Windows,
Linux and standalone headless archives retain their documented signing limits.
No test suites were run for this release. Build/package checks do not establish
fresh-install or complete physical acceptance on every platform. Local Bedrock
on macOS continues to require an Intel Mac.
